## Project Akhet is designed to utilize the latest AI methods to recognize Ancient Egyptian texts

Contact: humonen@airi.net

Current information and updates: https://imak.ai/projects/mummy-ancient-egyptian

## Models

- [`nllb-translation/`](nllb-translation/) — Middle Egyptian (hieroglyphs/transliteration) to
  English/German translation, weights on [Hugging Face](https://huggingface.co/kesha-humonen/egyptian-nllb).
